# Python Video Games



## Overview


This repository contains a few video games written entirely in python

## Games



### Lich's Fortress

Lich's Fortress is a text-based RPG game using only built-in python functions.


### Bubble Blaster

Bubble Blaster is a shooting game using tkinter


### Saint Sneak

Saint Sneak is a game where you play a preist and try to sneak around guards to do mass. It uses pygame and some game assets that are in the folder with it. In order to run Saint Sneak, you must download the code and all of the assets and keep them in the same folder and have pygame installed.

### Button Masher

Button Masher is a pygame game where you have to push a button that moves around the screen. You must have pygame installed to run this file.
